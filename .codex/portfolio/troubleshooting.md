# 트러블슈팅과 성능

## DB 권한 검사

모든 요청마다 DB를 조회하면 요청량 증가 시 불필요한 DB 부하가 발생한다. DB를 source of truth로 유지하되 권한 결과를 로컬 캐시하고 dry-run·reload로 누락과 변경을 관리하는 구조를 적용했다.

## 계약 확정 동시성

여러 제안이 동시에 들어오거나 수락될 수 있으므로 계약 요청을 잠그고 최종 계약 존재 여부를 다시 확인한다. 선택 제안은 수락하고 나머지는 거절한다.

## SSE 전달 보장

SSE 연결만으로는 재접속 시 알림이 유실될 수 있다. 알림을 먼저 RDB에 저장하고 Notification ID를 event ID로 사용해 `Last-Event-ID` 이후 알림을 replay한다.

로컬 성능 측정은 참고용이며, 배포 환경에서 동일 조건으로 재측정해야 한다.
