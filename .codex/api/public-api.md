# 공개 API와 개인정보

공개 API는 인증 없이 접근할 수 있지만, 공개 범위가 데이터 전체 공개를 의미하지 않는다.

## 공개 대상 예시

- 회원가입·로그인
- 대리점 목록·상세 검색
- 배송기사 회원가입 시 소속 대리점 검색

## 제한 원칙

- 다른 사용자의 계약 요청과 제안을 반환하지 않는다.
- 대리점 경쟁자의 제안 단가를 노출하지 않는다.
- 내부 User ID와 인증 정보를 노출하지 않는다.
- 목록에서는 전화번호, 사업자등록번호, 상세 주소를 기본 제외한다.
- 공개 접근 여부와 응답 필드 공개 여부를 별도로 판단한다.
