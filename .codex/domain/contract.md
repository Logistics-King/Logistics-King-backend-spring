# 최종 계약

최종 계약은 화주가 하나의 제안을 선택했을 때 생성되는 확정 거래다.

## 생성 규칙

- 계약 요청 하나에는 최종 계약이 최대 하나만 생성된다.
- 선택된 Proposal과 ContractRequest가 같은 요청에 속하는지 검증한다.
- 선택 제안은 수락하고 제출 상태인 다른 제안은 거절한다.
- 계약 요청은 계약 상태로 변경한다.

## 스냅샷

계약에는 계약 당시의 다음 정보를 저장한다.

- 픽업 지역·주소, 계약 유형, 회수·배송 일정
- 반복 회수 조건, 픽업 시간
- 품목 라인과 품목별 단가
- 토요일 배송, 반품, 콜드체인 조건

조회 시 현재 Product나 Proposal을 다시 조합하지 않는다.

## 조회

- 화주: `GET /api/v1/contracts/vendor/me`
- 대리점: `GET /api/v1/contracts/agency/me`
- 양쪽 응답에는 필요한 상대방 요약 정보만 포함한다.
- 로그인 사용자의 Vendor 또는 Agency ID로 조회 범위를 제한한다.
