# 배송 물품

## 품목 라인

- 계약 요청은 `items[]`를 가진다.
- 한 item은 하나의 `boxSize`, `boxQuantity`, `itemQuantity`, `coldChainType`을 가진다.
- 같은 품목명이라도 박스 규격이나 콜드체인이 다르면 item을 별도 라인으로 저장한다.
- 총 박스 수는 item별 `boxQuantity` 합계다.
- 계약 생성 시 계약 품목 라인에 단가와 조건을 스냅샷으로 복사한다.

## 템플릿

- Product는 화주 본인 품목 템플릿 관리용이다.
- 대리점은 품목 템플릿을 직접 일감으로 조회하지 않는다.
- 대리점 일감의 기준은 공개 ContractRequest다.

## 주요 조건

- 품목 카테고리와 품목명
- 박스 규격, 박스 수량, 낱개 수량
- 평균 무게
- 파손 주의, 액체, 신선식품 여부
- 콜드체인 타입
